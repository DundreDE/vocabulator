# Vocabulator

This is going to be a vocab trainer with flash cards. This project is developed through the hack club ysws "terra". You can genereate any account without an real email. (Note that password reset isn't working then.)

**Live Demo:** [vocabulator](https://vocabulator-cyan.vercel.app)

## At this point

This is the state of the 5. week of terra. I created skeleton loading on most of the sites this week. I also made the first steps into offline learning and created in the card mode the option (mostly for phones) to swipe and click the cards, so you don't have to click the buttons.

## Features

This is an vocab trainer. Create, edit and learn vocab deck online and the essentials also offline. Your decks from your account are shareable through links. You can learn your vocabs in three modes: Flipping card mode, typing mode and quiz mode. Also you can import anki decks or scan your vocabs and and AI makes is to a new deck.

## Tech Stack

- Next.JS with Tailwind CSS and TypeScript
- Backend Supabase
- AI Hackclub AI

## Running it locally

To run this project locally you must clone the repo and have nodejs installed. Then you can run following commands. You need to create an .env.local file see .env.example for an example.

```bash
git clone https://github.com/DundreDE/vocabulator.git
cd vocabulator
npm install
npm run dev
```

Or to test the production build instead:

```bash
git clone https://github.com/DundreDE/vocabulator.git
cd vocabulator
npm install
npm run build
npm run start
```
