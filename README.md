# Vocabulator

This is going to be a vocab trainer with flash cards. This project is developed through the hack club ysws "terra"

**Live Demo:** "Link here"

## At this point

This is the state of the second preparation week of terra. I tried creating the most basic systems in this week, I have completed the design and basic functionality of this project, but at this point everything is a prototype. There is no storage system.

## Features

At this point you can learn the one demo flash card deck and flip the cards and see at the end how many you got right.

## Tech Stack

- Next.JS with Tailwind CSS and TypeScript


## Running it locally

To run this project locally you must clone the repo and have nodejs installed. Then you can run following commands.

```bash 
git clone https://github.com/DundreDE/vocabulator.git 
cd vocabulator 
npm install 
npm run dev
```

Or to test the production build instead:

```bash 
git clone https://github.com/DundreDE/vocabulator.git 
cd vocabulator 
npm install 
npm run build
npm run start
```
